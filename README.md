# Aseer Quality (Demo)

A click-through **demonstration** of the Aseer Quality application, published so it can be shown to directors.

- **Live demo:** https://amrkz.github.io/aseer-quality-demo/
- **Fake data only.** Every facility, person and figure in this demo is invented. These are not real figures.
- It runs entirely in your browser. Nothing you enter is sent anywhere; it stays in your browser's local storage and can be reset from the footer.
- This repository holds only the compiled, minified demo build. **The source code is private** and is not published here.
